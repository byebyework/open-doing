# i18n(中英)全量接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** open-doing 全站「系统文案」接入中英双语,账号级语言偏好,存量中文渲染逐字不变。

**Architecture:** next-intl v4(无路由前缀,locale 来自请求);登录态以 `users.language` 为每请求权威(React `cache()` 去重),cookie 服务未登录页;Server Action 错误用自研轻量 translator(同一份 JSON,不依赖 next-intl 请求上下文,可单测);通知在客户端用 `useTranslations` 渲染,DB 不存文案。

**Tech Stack:** next-intl ^4.14(Next 16 / React 19 兼容)、antd v6 locale、dayjs locale、Drizzle 迁移、Vitest + Playwright。

**Spec:** `docs/superpowers/specs/2026-11-01-i18n-design.md`(实现前先读,本计划不再重复其背景与理由)

## Global Constraints

- 中文渲染**逐字不变**:zh.json 的文案从现有代码原样搬运,禁止顺手改写。
- 冻结契约不得修改:`docs/V1_TASKS.md` 的 `AppShell`、`(dashboard)/layout.tsx` 导入关系。
- `providers.tsx` 是唯一 ConfigProvider 入口(改造它,不自建第二个)。
- 时区口径不变:「今天」仍按 Asia/Shanghai(`todayInShanghai()`),日期主展示仍 `YYYY-MM-DD`;`packages/types` 不动。
- UI 对照 `docs/prototypes/`:本次只换文案来源,不改布局、不加顶栏切换按钮。
- 用户可见内容不翻译:任务标题/描述/评论、团队名、项目名、seed 数据。
- 测试环境:vitest/drizzle-kit 不读 `.env.local`,跑 DB 用例前先 `set -a; source apps/web/.env.local; set +a`;vitest 串行,勿开并行。
- 类型检查顺序:干净 checkout 先 `pnpm --filter @open-doing/web exec next typegen` 再 `pnpm typecheck`。
- commit message 用英文,结尾加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。
- next 相关写法先读 `apps/web/node_modules/next/dist/docs/` 对应章节。

### 模块迁移套路(Task 8–16 每个任务都按此执行)

1. 把该任务范围内所有用户可见中文字符串,按任务指定的 namespace 写入 `apps/web/src/i18n/messages/zh.json`(逐字)与 `en.json`(按术语表)。
2. RSC 组件:`const t = await getTranslations("<ns>");`(来自 `next-intl/server`)替换字面量;client 组件:`const t = useTranslations("<ns>");`。
3. RSC 传给 client 组件的中文 props → 改传 key + 参数,或 client 端自取。
4. 该模块 service/action 层的中文 `DomainError` 与 fallback 文案:throw 处加第三参 `{ key, params }`、message 改为 key 本身;action 的 `toFailure` 换用 Task 6 的共享 `domainFailureWith`(fallback 改传英文可读的 dev 兜底,如 `"unexpected error"`)。
5. 模块单测:zh 文案断言不变(渲染结果逐字一致);结构变化的断言改为断 `error.i18n.key`。
6. 验证:`set -a; source apps/web/.env.local; set +a; pnpm vitest run <该模块测试路径>`;`pnpm --filter @open-doing/web exec next typegen && pnpm typecheck`。全绿后 commit。
